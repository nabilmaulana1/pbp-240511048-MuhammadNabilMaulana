## 1. Tabel Perbandingan Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript, PHP | Java, C#, Python, C++ | Kotlin, Java, Swift |
| Arsitektur | Diakses melalui browser dan dapat terhubung ke server | Diinstal dan dijalankan pada sistem operasi komputer | Diinstal pada smartphone dan dapat menggunakan layanan server |
| Cara distribusi | Melalui alamat website tanpa instalasi khusus | Melalui installer atau toko aplikasi desktop | Melalui Play Store, App Store, atau sumber resmi |
| Keunggulan | Mudah diakses dari berbagai perangkat dan pembaruan dapat dilakukan melalui server | Cocok untuk pengolahan data, file lokal, dan pekerjaan yang membutuhkan sumber daya komputer | Praktis digunakan serta dapat memanfaatkan GPS, kamera, dan notifikasi |
| Keterbatasan | Membutuhkan browser dan koneksi internet untuk layanan online | Perlu instalasi dan penyesuaian terhadap sistem operasi | Perlu memperhatikan kapasitas baterai, penyimpanan, dan ukuran layar |
| Contoh aplikasi | Website pengajuan surat dan informasi akademik kampus | Aplikasi pengelolaan data mahasiswa di komputer administrasi | Aplikasi presensi mahasiswa menggunakan QR Code |
