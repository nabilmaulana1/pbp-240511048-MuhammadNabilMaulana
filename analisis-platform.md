# Analisis Komparatif Platform Pengembangan

| Aspek | Web | Desktop | Mobile |
| :--- | :--- | :--- | :--- |
| **Arsitektur** | Client-Server (Browser & Web Server) | Standalone / Client-Server (Sistem Operasi Lokal) | Client-Server / Native Mobile Architecture |
| **Bahasa Utama** | HTML, CSS, JavaScript, TypeScript | Java, C++, C#, Python | Swift, Kotlin, Java, Dart (Flutter) |
| **Distribusi** | Hosting Web & URL / Domain | File Installer (.exe, .dmg, .deb) | App Store (Google Play Store & Apple App Store) |
| **Keunggulan** | Akses cepat tanpa instalasi, pembaruan terpusat di server, lintas platform | Performa tinggi, akses penuh ke hardware lokal, dapat berjalan offline | Portabel, mendukung integrasi sensor (GPS, kamera, push notification) |
| **Keterbatasan** | Sangat bergantung pada internet, akses hardware terbatas di browser | Perlu instalasi di tiap perangkat, pembaruan harus dilakukan manual | Keterbatasan kapasitas daya/baterai, variasi ukuran layar |
| **Contoh Aplikasi** | Google Docs, Figma Web, Canva | Visual Studio Code, Adobe Photoshop, Microsoft Word | WhatsApp, Instagram, Gojek |
